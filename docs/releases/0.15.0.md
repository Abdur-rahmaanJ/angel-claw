# 0.15.0

Release notes for changes between `0.14.0` and `0.15.0`.

## Added

### SSO & Usage Tracking (ask-moris integration)
- SSO endpoints in the API module: issue API key, exchange for token, verify token
  (`src/angel_claw/app/modules/api/view.py`).
- Token-authenticated access for third-party integrations — no browser session needed.
- Usage tracking: new `usage_events` table via Alembic migration
  (`ac5e91f02b7d_add_usage_events_table.py`), recorded through `credits.py`.
- New admin **Usage** dashboard view (`agent/views/usage.html`) with per-key / per-token
  consumption stats, linked from the agent sidebar.

### Mobile Chat API
- SSE streaming of chat responses under token auth — responses arrive chunk by chunk
  instead of one blocking call.
- Ephemeral mobile chats: integrations can start throwaway conversations that stay out
  of the normal chat UI.
- API key auth support hardened for mobile pairing.

### Configuration UI (module: `configs`)
- Full `.env` editor in the dashboard covering **every** variable documented in
  `docs/configuration.md` — 30 variables across 9 sections (LLM, Gateway, Security &
  Sandboxing, Scalability, Performance, Bridge, MCP, Email, Google Calendar).
- Schema-driven rendering (`modules/configs/schema.py`): text / password / number /
  checkbox / select / textarea inputs with hints and defaults.
- Secrets masked (`sk-1...cdef`) — blank field keeps the stored value, never echoed back.
- `.env` is auto-created with documented defaults when missing; existing files are
  updated in place, comments and unknown keys preserved (atomic write).
- Input validation: no newline injection, numbers must be integers, `MCP_SERVERS` /
  `MCP_AUTH` must be valid JSON.
- Hot-apply: saved values push straight into the live settings object via validation
  aliases (with type coercion); LLM network validation only runs when LLM fields change.

## Tests
- `tests/test_sso_usage.py`: SSO key/token/verify flow + usage tracking.
- `tests/conftest.py`: app test fixtures.
- `modules/configs/tests/`: guard test asserting the schema covers every `` `KEY` `` row
  in `docs/configuration.md`, plus `.env` creation, secret-keep and validation tests.

## Changed
- Version bumped `0.14.0` → `0.15.0`.
